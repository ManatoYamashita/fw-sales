# Product Overview

**FirstWeb - Reserch AI for Sales** — 飲食店向け WEB 集客サービス (MEO / HP / Instagram) を扱う社内営業チームのための、リード〜受注〜引き継ぎを一気通貫で管理する社内ツール。

## Core Capabilities

- **店舗 (Store) 管理**: 営業対象の飲食店マスタ。優先度・チャネル(DM/テレアポ)推奨・ステージ・担当者を一元管理
- **調査 (Research) → 商談 (Deal) → 引き継ぎ (Handoff) のライフサイクル管理**: 12 ステージのパイプラインに沿って状態遷移
- **アクション支援**: URL 解析(食べログ・Google マップ)、DM / テレアポ文面の自動生成、実行記録
- **KPI / ダッシュボード / Kanban パイプライン**: ファネル変換率・チャネル内訳・アクションキューを可視化
- **データ移送**: JSON Export / Import / Reset(SEED 復元)

## Target Use Cases

- 営業担当者が日々の架電・DM 送信ターゲットを優先度順に確認する
- プランナー / 調査担当が店舗の現状(レビュー・MEO ギャップ等)を記録し、推奨チャネルを判定する
- マネージャーが KPI ダッシュボードでチームのファネル健全性を確認する
- 受注後、運用チームへの引き継ぎ情報を漏れなく受け渡す

## Value Proposition

- **ステージドリブン**: 12 段階の営業ステージを軸にしたデータモデルで、状況把握と次アクションが一目で分かる
- **チャネル戦略の自動化**: 調査結果から DM / テレアポの推奨を自動判定し、文面テンプレートまで生成
- **将来の DB 化を見越した抽象化**: Mock データ層は Repository インターフェース越しに使われており、本番 DB への差し替えを最小コストで実施できる
- **Cache Components による高速 RSC**: マスタ・集計データはタグ単位で stale-while-revalidate される

---
_社内ツールとして「営業フローに沿って迷わず操作できる」ことを最優先。汎用 CRM ではなく、飲食店 × WEB 集客に特化した語彙とフローで設計されている。_
