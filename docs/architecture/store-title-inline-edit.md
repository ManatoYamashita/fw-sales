# 店舗タイトルのインライン編集

店舗詳細の店舗名・業態は、表示していた文字の場所を入力欄へ置換する。
別の場所へフォームを追加して元のタイトルを重複表示しない。
地域情報と状態バッジは編集中も残す。
別タスクの次アクション案内と店舗名の営業メモ案内は編集中に隠す。

`InlineTitleField` は同じフォント・行高の文字ミラーで枠の寸法を保ち、
編集中はその枠にtextareaを重ねる。ミラーは `aria-hidden` かつ不可視にする。
入力欄の文字サイズ・行高・文字間隔は親から継承し、内側余白を加えない。
業態を含む地域情報行はモバイルで16px、デスクトップで14pxとし、表示と編集で揃える。
枠線はringで表現するため、文字の始点をずらさない。
長い値と末尾改行もミラーへ反映し、折り返し後の内容を切らない。
`field-sizing` の対応状況に依存しない。

## 編集操作の位置 (#321)

編集の開始と確定は、見出し内の同じ位置で行う。
表示中は状態バッジの右に鉛筆ボタンを置き、編集中は同じ位置を「保存」「キャンセル」に差し替える。
差し替えは `TitleEditActions` の 1 か所で行い、業態欄の下などへ操作を重複して出さない。
#314 では業態欄の直下に置いたが、編集を始めた場所と確定する場所が離れるため改めた。

操作ボタンは鉛筆ボタンと同じ `size="sm"` にし、見出し行の高さを変えない。
デスクトップ幅では見出し行に収まり、業態の入力位置は表示中と変わらない。
狭い幅や長い店舗名では、操作グループは見出しの中で次の行へ折り返す。
このとき業態の行は下へずれるが、店舗名の入力枠は表示中の文字と同じ位置に留まる。
操作グループは縮めず (`shrink-0`)、ボタンの文字を折り返さない。

保存中は保存ボタンに `pending` を渡し、キャンセルと入力欄は `disabled` にする (#326)。
保存は `runAction` を通し、結果をトーストで知らせる (#327)。
保存・キャンセルで操作グループが消えたら、フォーカスを鉛筆ボタンへ戻す。
タブ順は見た目の順 (店舗名 → 保存 → キャンセル → 業態) に従う。

## 下書きと検証

編集開始・キャンセルは保存済みpropsから下書きを初期化する。
入力欄にはラベルを付け、店舗名の必須エラーを関連付けてフォーカスを戻す。

変更時は表示と編集の枠座標を比較し、狭幅・デスクトップ・長い値・キャンセル・必須検証を確認する。
`e2e/store-title-inline-edit.spec.ts` が操作の位置、キーボード操作、375px と 1280px で長い店舗名を入れたときの重なり・見切れを測る。
`<body>` は `overflow-x: clip` のため、横スクロールの有無だけでは見切れを検出できない。
ボタンと入力枠の座標が画面幅に収まることも測る。
本番データでの確認では保存せず、未保存の変更はキャンセルする。

関連: [Issue #310](https://github.com/ManatoYamashita/fw-sales/issues/310)、[#321](https://github.com/ManatoYamashita/fw-sales/issues/321)、#303。

## 基本情報の編集導線 (#314)

#314 で「基本情報待ち」状態の次アクションを「基本情報を編集」(`/stores/[id]/edit`) に直したが、
#300 で店舗詳細の状態を「営業資産 未生成 / 生成済み」の 2 つに縮退したため、その次アクションは廃止した
(未生成の次アクションは「AI調査から始める」)。基本情報の編集は店舗詳細の「編集」ボタンから入る。
以下は編集フォームへの導線を新たに置くときの規則として残す。

基本情報の編集導線は `/stores/[id]/edit` の実際の編集フォームへ遷移する。
既に表示中の閲覧タブを指すリンクを入力の入口にしない。
補助文は編集できる項目を示し、53項目の調査情報や生成処理と混同させない。
変更時はクリック・キーボードから入力欄が開くことと、キャンセルで詳細へ戻れることを確認する。
編集ページのrequest-time paramsとデータ取得は、ページ内Suspenseの子で読む。
詳細ページからのクライアント遷移も確認し、共有レイアウトの境界だけに依存しない。
