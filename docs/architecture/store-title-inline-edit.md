# 店舗タイトルのインライン編集

店舗詳細の店舗名・業態は、表示していた文字の場所を入力欄へ置換する。
別の場所へフォームを追加して元のタイトルを重複表示しない。
地域情報、状態バッジ、次のアクションは編集中も残す。

`InlineTitleField` は同じフォント・行高の文字ミラーで枠の寸法を保ち、
編集中はその枠にtextareaを重ねる。ミラーは `aria-hidden` かつ不可視にする。
入力欄の文字サイズ・行高・文字間隔は親から継承し、内側余白を加えない。
枠線はringで表現するため、文字の始点をずらさない。
長い値と末尾改行もミラーへ反映し、折り返し後の内容を切らない。
`field-sizing` の対応状況に依存しない。

鉛筆ボタンは編集中に不可視・操作不可にし、元の占有領域を保つ。
ボタンを削除して見出し行の高さが変わると、業態の入力位置も移動するためである。
編集開始・キャンセルは保存済みpropsから下書きを初期化する。
入力欄にはラベルを付け、店舗名の必須エラーを関連付けてフォーカスを戻す。

変更時は表示と編集の枠座標を比較し、狭幅・デスクトップ・長い値・キャンセル・必須検証を確認する。
本番データでの確認では保存せず、未保存の変更はキャンセルする。
